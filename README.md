## English

# SteamID64 to GUID Converter

100% client-side (HTML/JS) tactical tool for DayZ and Arma server administrators and developers. Converts SteamID64 to the native hash formats of the Enfusion/Real Virtuality engine and checks the account status on SteamRep.

## Features
- **DayZ Hashed ID**: Generates the Base64 (URL-Safe) of the plain text SHA256, used in `.rpt` files and DayZ Standalone profiles.
- **BattlEye / Classic Arma**: Generates the Hexadecimal MD5 from Little Endian bytes, used in classic GUIDs and bans.
- **Automatic Formatting**: Automatically generates the line for the BattlEye `bans.txt` file.
- **SteamRep Checker**: Extracts the profile picture, username, and verifies the status of VAC, Trade Bans, and general reputation without exposing API Keys (via public proxy).
- **Client-Side and Serverless**: All cryptographic processing runs locally in the browser. No backend or database required.

## Quick Usage
1. Go to the [Web App](https://www.github.com/SurvivorF-Eliana/SteamID-to-GUID-HTML-Tool/index.html).
2. Paste the SteamID64 (e.g., `76561198000000000`) or the full link to the Steam profile.
3. Click on any result box to copy the value to the clipboard.

## Deployment (Hosting)
Since it has no dependencies or backend, you can host it for free on GitHub Pages, Cloudflare Pages, or directly open the `index.html` file on your PC offline (profile features require internet).
